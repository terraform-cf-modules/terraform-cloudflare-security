# turnstile

Manages `cloudflare_turnstile_widget`, Cloudflare's CAPTCHA replacement.

```hcl
module "turnstile" {
  source  = "terraform-cf-modules/security/cloudflare//modules/turnstile"
  version = "~> 0.1"

  account_id = var.account_id

  widgets = {
    signup = {
      name    = "Signup form"
      domains = ["example.com", "www.example.com"]
      mode    = "managed"
    }

    api = {
      name           = "API clients"
      domains        = ["api.example.com"]
      mode           = "invisible"
      bot_fight_mode = true
    }
  }
}
```

## Secrets

The widget secret key is generated by Cloudflare, marked `SENSITIVE` in the provider schema, and lands in
Terraform state. It is exposed through the `secrets` output, which is `sensitive = true`. Feed it to whatever
runs the `/siteverify` call, for example a Workers secret or a secrets manager entry; never print it.

The `sitekey` is public and goes in the HTML.

## Notes

- `mode` is one of `managed`, `non-interactive`, `invisible`.
- `region` cannot be changed after creation. Editing it replaces the widget, which changes the sitekey and
  breaks every page embedding it.
- `offlabel` and `ephemeral_id` are Enterprise only.
- `clearance_level` only applies when the widget sits on a domain proxied through the same Cloudflare account.
- Domains are matched exactly. `example.com` does not cover `www.example.com`; list both.
